# SafeBite UX Core Scenarios (UX FLOW)

이 문서는 SafeBite 프로토타입 앱의 핵심 사용자 경험(UX) 흐름을 정의합니다.

## 1. 다중 사용자 프로필 설정 (Profile Setup Flow)
사용자는 가족 구성원의 복잡한 알레르기 정보를 쉽게 등록하고 관리할 수 있습니다.
* **진입점**: 하단 내비게이션 `프로필` 탭 -> `새 프로필 추가` 버튼
* **UX 단계 (Wizard)**:
  1. **대상 지정**: 누구를 위한 프로필인지 이름 지정 (예: "준 (아들)").
  2. **유발 물질 선택**: 땅콩, 우유, 글루텐 등 공통 알레르기 물질 다중 선택.
  3. **민감도 설정**: 아나필락시스 위험(심각), 불내증(중간), 정보 제공 목적(경미) 중 선택.
* **결과**: 앱 전역에서 사용할 수 있는 컬러 코딩된 프로필 카드가 생성되며, 이후 스캔 시 해당 프로필을 기준으로 검증합니다.

## 2. 즉석 바코드 스캔 및 안전 검증 (Instant Scan Flow)
앱의 가장 핵심적인 기능으로, 매장에서 제품의 안전성을 즉각적으로 확인합니다.
* **진입점**: 홈 화면 중앙 `즉석 안전 스캔` 카드 탭 또는 내비게이션 `스캔` 탭
* **UX 단계**:
  1. **스캐너 뷰파인더**: 카메라 UI가 로드되며 대상 프로필을 상단 드롭다운에서 선택/변경 가능합니다.
  2. **애니메이션 피드백**: 하단 스캔 버튼 탭 시 뷰파인더에 `분석 중...` 맥박(pulse) 애니메이션이 동작하여 시스템의 처리 상태를 시각화합니다.
  3. **자동 라우팅**: 분석이 완료되면(현재 2초 지연 시뮬레이션), 선택된 프로필 데이터를 파라미터로 안고 `/result` 화면으로 이동합니다.

## 3. 지능형 결과 판독 및 근거 확인 (Verdict & Rationale Flow)
스캔된 제품의 성분을 분석하여 명확한 행동 지침과 그 이유를 제공합니다.
* **진입점**: 스캔 완료 후 자동 라우팅 (`/result`)
* **UX 단계**:
  1. **스켈레톤 로딩**: 성분 분석(Genkit 통신)이 진행되는 동안 스켈레톤 UI를 보여줍니다.
  2. **직관적 판독 (Verdict)**: 분석 완료 즉시 화면 전체 배경색과 큰 아이콘을 통해 직관적으로 안전(Green) 또는 위험(Red)을 통보합니다.
  3. **스마트 성분 분석**: 라벨 성분 중 어느 것이 플래그(위험) 처리되었는지 뱃지로 표시합니다.
  4. **과학적 근거 아코디언**: 위험 성분 클릭 시 Genkit AI 서버 액션(`getAllergenRationale`)이 호출되며, 과학적 이유와 공식 출처 링크가 확장되어 보입니다.

## 4. 관리자 커맨드 센터 (Admin Integrity Flow)
사용자 리포트 및 데이터 무결성을 관리하는 B2B/운영자 측면의 플로우입니다.
* **진입점**: 내비게이션 `관리자` 탭
* **UX 단계**:
  1. **실시간 통계 모니터링**: 대기 중 리포트, 검증률, 정확도 등 핵심 지표를 확인합니다. (새로고침 인터랙션 포함)
  2. **대기열 처리 (Queue)**: 사용자가 신고한 '바코드 불일치'나 '성분 누락' 정보를 긴급도(색상 띠)에 따라 분류하여 확인하고, 즉각적으로 승인(Check) 또는 거절(X) 처리합니다.
