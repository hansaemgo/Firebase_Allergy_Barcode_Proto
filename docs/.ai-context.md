# SafeBite AI Context
*This document provides compressed context and strict guidelines for AI agents working on this codebase.*

## 🏗 Project Architecture (Next.js App Router)
- **Root**: `src/app/layout.tsx` (Contains global styles and Toaster)
- **Pages**:
  - `/`: `src/app/page.tsx` (Home dashboard)
  - `/scan`: `src/app/scan/page.tsx` (Barcode scanner UI)
  - `/result`: `src/app/result/page.tsx` (Genkit-powered rationale and verdict)
  - `/profiles`: `src/app/profiles/page.tsx` (User allergy profiles)
  - `/alerts`: `src/app/alerts/page.tsx` (Recalls and community alerts)
  - `/admin`: `src/app/admin/page.tsx` (Data integrity dashboard)

## 🎨 UI & Styling Rules
1. **Shadcn UI**: Located in `src/components/ui/`. **Do not** write vanilla HTML buttons or inputs. Always import from `ui/*`.
2. **Card Component**: `src/components/ui/card.tsx` has been refactored with `cva` to support variants: `default`, `primary`, `secondary`, `success`, `destructive`, `caution`. Use these variants instead of manually defining borders and background colors.
3. **Mobile Layout**: Currently, pages hardcode `<div className="max-w-md mx-auto min-h-screen bg-background pb-20">` and `<AppNav />`. When creating new pages, ensure you follow this mobile-first constraint until a unified `MobileLayout` component is implemented.

## 📝 Documentation Rules (Strict)
When creating or modifying files, you MUST adhere to the following commenting standard:
1. **File Name**: `// 파일명: src/.../filename.ts` at the very top (after `use client`/`use server`).
2. **Overview**: JSDoc `@overview` tag explaining the file's purpose. Must include `<!-- AI Guideline: Refer to docs/.ai-context.md before processing -->`.
3. **Functions/Components**: JSDoc block with `@function`, `@description`, and `@param` tags immediately before the declaration.
4. **Logic Sequences**: For complex operations, add a `[호출 구조 및 순서]` list to explain the flow.

## 🧠 AI Integration (Genkit)
- Server actions utilizing AI are in `src/ai/flows/`.
- Ensure strict Zod schema validation for all Genkit inputs/outputs.
